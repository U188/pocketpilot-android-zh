# 🚀 PocketPilot

**Управляй сервером и AI-агентом для кода прямо с телефона.**
SSH, файловый менеджер, редактор кода, терминал и чат с [OpenCode](https://opencode.ai) в одном Android-приложении.

> *PocketPilot is an Android client for OpenCode with an SFTP file manager, code editor and SSH terminal.*

![status](https://img.shields.io/badge/status-beta-orange)
![platform](https://img.shields.io/badge/platform-Android%208.0%2B-green)

> ⚠️ Неофициальный клиент. Проект не связан с командой OpenCode и не одобрен ею.

---

## ✨ Зачем это нужно

Если твой код живёт на VPS, а под рукой только телефон, обычно приходится держать несколько приложений: SSH-клиент, редактор, чат с ИИ. PocketPilot собирает всё в одном месте и работает с **твоим** сервером, без чужих облаков.

## 📦 Возможности

**Готово**
- [x] Профили серверов, подключение по SSH (пароль или ключ)
- [x] Файловый менеджер по SFTP: навигация, сортировка, поиск, копирование, перемещение, удаление, chmod
- [x] Загрузка и скачивание файлов с очередью передач
- [x] Редактор кода: подсветка синтаксиса, поиск и замена, Undo/Redo, панель спецсимволов, защита от конфликтов при сохранении
- [x] Чат с OpenCode: сессии, стриминг ответов, выбор агента и модели, разрешения агента, просмотр диффов
- [x] SSH-терминал с панелью Ctrl / Alt / Esc / Tab и автоподключением к tmux
- [x] Работа в фоне: фоновая служба, автопереподключение, сохранение состояния экранов
- [x] Установка OpenCode на сервер одной кнопкой (systemd-служба, автозапуск, защита паролем)
- [x] Подключение собственной модели (любой провайдер, совместимый с OpenAI API)
- [x] Самообновление из GitHub Releases

**В планах**
- [ ] Выбор рабочей папки (проекта) для агента
- [ ] Время отправки у каждого сообщения чата
- [ ] Биометрическая блокировка приложения

## 🔧 Как это работает

```
Телефон (PocketPilot) ──SSH-туннель──▶ Твой VPS
                                        ├─ opencode serve (только 127.0.0.1)
                                        └─ файлы проектов (SFTP)
```

Приложение ничего не запускает на телефоне. Все данные остаются между тобой и твоим сервером.

## 📲 Установка

1. Открой раздел [**Releases**](../../releases/latest).
2. Скачай `app-debug.apk`.
3. Разреши установку из браузера и установи.

Дальше приложение само сообщит о новой версии и предложит обновиться.

## 🖥️ Подготовка сервера

Достаточно подключиться к серверу в приложении: на вкладке «Чат» появится кнопка **«Установить и настроить OpenCode»**. Она поставит OpenCode, создаст systemd-службу и проверит работу.

Если хочешь сделать это вручную:

```bash
curl -fsSL https://opencode.ai/install | bash
opencode serve --port 4096
```

Подключение идёт через SSH-туннель, поэтому порт 4096 наружу открывать **не нужно**.

## 🔒 Безопасность

- Пароли и ключи хранятся в Android Keystore
- Проверка host key сервера
- OpenCode слушает только `127.0.0.1`
- Без аналитики и телеметрии

Приложение распространяется как debug-сборка. Скачивай APK только из раздела Releases этого репозитория.
